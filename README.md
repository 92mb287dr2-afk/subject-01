# Subject-01 — Artificial Organism

Экспериментальная автономная среда искусственной жизни. Проект не заявляет о создании сознания: цель — исследовать появление схемы тела, агентности, предсказания, памяти и self-model-подобных представлений.

> Статус: **PRE-BIRTH**. Subject-01 ещё не создан. Сначала должны пройти тесты мира, вмешательств и сохранений.

## Открыть визуальную среду (v0.2 diagnostic observer)

Windows: скачайте ZIP репозитория через **Code → Download ZIP**, распакуйте
и запустите **start-observer.bat**. Требуется установленный Python 3.11+,
доступный командой `python`. Откроется браузер на http://127.0.0.1:8765.

Или после установки проекта:

```bash
subject01-observer
# Без установки пакета, из корня репозитория (Linux/macOS):
PYTHONPATH=src python -m subject01.observer
```

В окне:
- поляна с условным гуманоидным телом (вид сверху);
- кликом «Добавить объект» и затем на поляну можно менять среду;
- отдельный граф на 32 узла: ощущения, внутренние, движение, предсказание;
- узлы можно выбирать и перетаскивать, граф — масштабировать и разворачивать;
- яркость узла — величина его активности; толщина ребра — модуль веса;
- световые точки — реальные ненулевые передачи сигналов по рёбрам;
- золотое ребро — новая связь, созданная правилом обучения;
- журнал создания связей, изменения весов и передачи сигналов;
- выгрузка полного `neural-events.jsonl`;
- сохранение кнопкой и автоматически каждые 200 тиков.

Сервер работает **на вашем компьютере**, не на GitHub. Вкладку можно закрыть:
мир продолжится, пока работает Python. Ctrl+C в консоли сохраняет и останавливает
процесс. После повторного запуска продолжается сохранённое симуляционное время;
время выключенного процесса не симулируется.

### Научные границы этой версии

Это **PRE-BIRTH / DIAGNOSTIC**, не официальное рождение Subject-01.
Гуманоид на экране — символ точечного тела, не симуляция скелета.
Восемь числовых ощущений: близость четырёх границ, объектов слева/справа,
внутренняя энергия и скорость. Мозг не получает имён объектов или команд наблюдателя.

Фиксированные сенсорные и моторные проекции плюс seed-зависимая внутренняя
активность создают исходное движение. Обучается только разреженная сеть
предсказания следующих ощущений (delta rule); новые связи выбираются по
градиенту ошибки не чаще раза в 40 тиков. Моторные веса пока не обучаются.
Анимация не доказывает сознание, понимание мира или освоенную ходьбу.
Сигналы — числовые передачи rate-модели, не биологические потенциалы действия.

Данные хранятся отдельно в `data-observer/`, старые `data/` не изменяются.
Нейронный журнал растёт постоянно: в нём все ненулевые передачи и изменения весов,
поэтому длительные эксперименты требуют контроля свободного места.
Онлайн-буфер хранит 240 тиков; пропуски при долгом отключении отмечаются явно,
полный записанный поток остаётся в журнале. После аварии восстанавливается последний
снимок; автоматического replay журнала пока нет. Запускайте один процесс на каталог.

Для просмотра с iPhone по сети нужен отдельный безопасный доступ; текущий сервер
специально слушает только 127.0.0.1, не открыт в интернет.

## v0.1 foundation

- детерминированный фиксированный шаг симуляции;
- мир работает независимо от консоли наблюдателя;
- вмешательства применяются только на границе тика и получают последовательный ID;
- объекты можно добавлять, толкать и удалять без перезапуска;
- гравитацию можно менять во время работы;
- append-only журнал событий JSONL;
- атомарные JSON-снимки и восстановление;
- PRNG с сохраняемым состоянием;
- birth manifest с seed, конфигурацией и версией архитектуры;
- тесты детерминизма, порядка команд и snapshot round-trip.

## Запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
subject01 --data-dir ./data
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
subject01 --data-dir ./data
```

Примеры команд:

```text
spawn 20 20 stone
impulse obj-1 4 -2
gravity 3
status
save
remove obj-1
quit
```

Пока консоль ждёт команду, мир продолжает работать.

## Инварианты

- UI наблюдателя не управляет временем мира.
- Метаданные наблюдателя не доступны будущему мозгу.
- В момент рождения нет языка, имени, понятий «я», смерти или reward score.
- Обучение начинается как predictive/self-supervised.
- Любое внешнее вмешательство журналируется.
- Рождение запрещено до прохождения базовых тестов.
